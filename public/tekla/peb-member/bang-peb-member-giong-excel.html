Bảng PEB Member nay thao tác như Excel

Nếu bạn đã quen nhập liệu trong Excel thì giờ có thể làm y như vậy ngay trong bảng PEB Member: copy, dán, kéo điền, di chuyển ô bằng phím mũi tên. Bài này điểm qua những gì mới trong bản 1.3.28.

  • Phiên bản 1.3.28
  • Cập nhật 04/10/2026
⬇ Tải bản 1.3.28 Xem bài giới thiệu PEB Member

Tóm tắt nhanh

  • Ctrl+A / C / X / V chỉ tác động vào ô đang đứng.
  • Chọn cả hàng, copy rồi dán sang hàng khác.
  • Di chuyển như Excel: mũi tên, Enter, Ctrl+mũi tên, Shift để chọn vùng.
  • Kéo điền: Prefix C1 kéo xuống thành C2, C3…
  • Cột Type gợi ý tự điền khi gõ.

1. Ctrl+A, Ctrl+C, Ctrl+V chỉ tác động vào ô đang đứng

Khi con trỏ đang ở một ô:

  • Ctrl+A chỉ chọn chữ trong ô đó, không quét cả bảng như trước.
  • Ctrl+C / Ctrl+X chép hoặc cắt cả giá trị của ô (nếu bạn bôi đen một phần chữ thì chỉ chép phần đó).
  • Ctrl+V dán đúng vào ô đó.

2. Chọn cả hàng, copy cả hàng, dán sang hàng khác

Bấm vào số thứ tự (hoặc vùng trống) của hàng để chọn cả hàng; bấm kèm Shift hoặc Ctrl để chọn nhiều hàng.

  • Ctrl+C / Ctrl+X chép hoặc cắt cả hàng (Type, Prefix, Profile).
  • Ctrl+V dán sang hàng khác:
    • chép 1 hàng, chọn nhiều hàng đích → dán vào tất cả các hàng đó;
    • chép nhiều hàng → dán dàn xuống từ hàng đầu tiên đang chọn, tự thêm hàng mới nếu hết bảng;
    • chép 1 giá trị đơn rồi chọn nhiều hàng → giá trị được dán vào cột của ô đang đứng ở mọi hàng đang chọn.
  • Delete / Backspace xoá nội dung các hàng đang chọn (hàng vẫn còn).
  • Ctrl+A chọn tất cả các hàng.

3. Di chuyển như Excel

PhímTác dụng
↑ ↓ ← →Sang ô kế bên (← → chỉ chuyển ô khi con trỏ đã ở mép chữ, nên vẫn sửa chữ trong ô bình thường)
Enter / Shift+EnterXuống / lên một ô
Shift + mũi tênMở rộng vùng chọn nhiều ô
Ctrl + mũi tênNhảy tới ô đầu/cuối của hàng hoặc cột
Ctrl+Home / Ctrl+EndVề ô đầu / ô cuối của bảng
Shift + clickChọn hình chữ nhật từ ô đang đứng tới ô vừa bấm
Ctrl + clickThêm hoặc bớt từng ô khỏi vùng chọn

Khi chuyển ô bằng bàn phím, chữ trong ô mới được bôi đen sẵn, gõ vào là thay luôn.

4. Nắm kéo điền (fill handle)

Ô vuông nhỏ ở góc dưới-phải của ô hoặc vùng đang chọn. Kéo xuống, lên hoặc sang ngang để điền:

  • Ô Prefix có đuôi số sẽ điền theo dãy: C1 → C2, C3…
  • Các ô khác lặp lại giá trị nguồn.
  • Ctrl+D điền xuống, Ctrl+R điền sang phải.

5. Những chi tiết nhỏ

  • Ô vừa copy/cut có viền nét đứt xanh cho tới khi bạn gõ vào ô hoặc nhấn Esc.
  • Esc khi đang sửa ô sẽ huỷ chỉnh sửa và trả lại giá trị cũ; Esc lần hai bỏ vùng chọn.
  • Ctrl+Z hoàn tác các thao tác trên (dán, điền, xoá…).
  • Ctrl+– xoá cả hàng đang chọn.
  • Bạn có thể dán thẳng một vùng ô từ Excel vào bảng.

6. Cột Type: gợi ý tự điền khi gõ

Không còn danh sách thả xuống. Khi bạn gõ, tool tự điền sẵn loại gần nhất (ví dụ gõ ra → Rafter, phần điền thêm được bôi đen). Đồng ý thì nhấn Tab (hoặc Enter) là xong; muốn khác thì cứ gõ tiếp. Nhấn Backspace/Delete thì không tự điền.

Gợi ý lấy từ: các loại có sẵn, các loại bạn đã nhập trước đó (được nhớ lại cho cả những lần mở sau, kể cả khi hàng đó đã xoá), và các loại đang có trong bảng.

Lưu ý

  • Các thao tác trên áp dụng cho bảng PEB Member; bảng Base Plate giữ cách nhập cũ.
  • Copy một vùng chọn rời rạc (nhiều ô chọn bằng Ctrl+click) sẽ lấy cả hình chữ nhật bao quanh.
  • Kéo điền chỉ điền trong các hàng đã có, không tự thêm hàng.

The PEB Member table now works like Excel

If you are used to entering data in Excel, you can now do the same right in the PEB Member table: copy, paste, drag-fill and move between cells with the arrow keys. Here is what is new in version 1.3.28.

  • Version 1.3.28
  • Updated Oct 4, 2026
⬇ Download 1.3.28 Read the PEB Member overview

At a glance

  • Ctrl+A / C / X / V only act on the current cell.
  • Select whole rows, copy them and paste onto other rows.
  • Move like Excel: arrows, Enter, Ctrl+arrows, Shift to select a range.
  • Drag-fill: a Prefix of C1 dragged down becomes C2, C3…
  • The Type column suggests a completion as you type.

1. Ctrl+A, Ctrl+C, Ctrl+V act on the current cell only

While the cursor is in a cell:

  • Ctrl+A selects only the text in that cell, no longer the whole table.
  • Ctrl+C / Ctrl+X copy or cut the whole cell value (or only the part of the text you highlighted).
  • Ctrl+V pastes right into that cell.

2. Select, copy and paste whole rows

Click a row's number (or its empty area) to select the whole row; hold Shift or Ctrl to select several rows.

  • Ctrl+C / Ctrl+X copy or cut the whole row (Type, Prefix, Profile).
  • Ctrl+V pastes onto other rows:
    • copy 1 row and select several target rows → it is pasted into all of them;
    • copy several rows → they are pasted downward from the first selected row, adding new rows if the table runs out;
    • copy a single value and select several rows → the value is pasted into the current cell's column in every selected row.
  • Delete / Backspace clears the selected rows' contents (the rows stay).
  • Ctrl+A selects all rows.

3. Move around like Excel

KeyEffect
↑ ↓ ← →Move to the neighbouring cell (← → only change cell when the cursor is at the edge of the text, so you can still edit text inside a cell)
Enter / Shift+EnterDown / up one cell
Shift + arrowExtend the selection over several cells
Ctrl + arrowJump to the first/last cell of the row or column
Ctrl+Home / Ctrl+EndGo to the first / last cell of the table
Shift + clickSelect the rectangle from the current cell to the clicked cell
Ctrl + clickAdd or remove single cells from the selection

When you change cell with the keyboard, the text of the new cell is already highlighted, so typing replaces it.

4. The fill handle

The small square at the bottom-right of the current cell or selection. Drag it down, up or sideways to fill:

  • A Prefix ending in a number fills as a series: C1 → C2, C3…
  • Other cells repeat the source value.
  • Ctrl+D fills down, Ctrl+R fills right.

5. Small details

  • A cell you just copied or cut gets a dashed blue border until you type in a cell or press Esc.
  • Esc while editing a cell cancels the edit and restores the old value; a second Esc clears the selection.
  • Ctrl+Z undoes the actions above (paste, fill, clear…).
  • Ctrl+– deletes the selected rows.
  • You can paste a block of cells straight from Excel into the table.

6. Type column: autocomplete as you type

The drop-down list is gone. As you type, the tool fills in the closest match (for example ra → Rafter, with the added part highlighted). Press Tab (or Enter) to accept it, or just keep typing for something else. Backspace/Delete do not autocomplete.

Suggestions come from: the built-in types, the types you entered before (remembered for later sessions, even after the row is deleted), and the types currently in the table.

Notes

  • These actions apply to the PEB Member table; the Base Plate table keeps its old way of entering data.
  • Copying a non-contiguous selection (several cells picked with Ctrl+click) takes the whole bounding rectangle.
  • Drag-fill only fills existing rows; it does not add rows.
