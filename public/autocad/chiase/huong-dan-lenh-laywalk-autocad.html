Hướng Dẫn Lệnh LAYWALK Trong AutoCAD: Duyệt Từng Layer Để Kiểm Tra Bản Vẽ

LAYWALK in AutoCAD: Walk Through Layers to Audit a Drawing

Nhận một bản vẽ có hàng chục, thậm chí hàng trăm layer, bạn thường chẳng biết layer nào chứa gì. Mở bảng Layer rồi bật tắt từng cái rất mất thời gian. LAYWALK giải quyết việc này: nó cho bạn "đi dạo" qua từng layer, chọn layer nào thì bản vẽ chỉ hiện layer đó.

When you receive a drawing with dozens or even hundreds of layers, you rarely know what each one holds, and toggling layers one by one in the Layer palette is slow. LAYWALK lets you "walk" through the layers: select a layer and the drawing shows only that layer.

Cách dùng LAYWALK cơ bản

Basic use of LAYWALK

  • Gõ LAYWALK và nhấn Enter để mở hộp thoại Layer Walk.Type LAYWALK and press Enter to open the Layer Walk dialog.
  • Hộp thoại liệt kê các layer trong bản vẽ. Bấm vào một layer thì chỉ layer đó hiển thị trên màn hình.The dialog lists the layers in the drawing. Click a layer and only that layer is displayed.
  • Giữ Ctrl hoặc Shift để chọn nhiều layer cùng lúc và xem chúng cùng nhau.Hold Ctrl or Shift to select several layers and view them together.
  • Nút Select Objects cho phép bạn chọn đối tượng ngay trên bản vẽ, hộp thoại sẽ chọn các layer chứa đối tượng đó. Rất tiện để tìm "đối tượng này nằm ở layer nào".The Select Objects button lets you pick objects in the drawing and the dialog selects the layers that contain them. Handy for answering "which layer is this object on?".
  • Xong việc, đóng hộp thoại để trở về trạng thái layer ban đầu (nếu ô Restore on exit được tích).When finished, close the dialog to return to the original layer state (if Restore on exit is ticked).
Luôn kiểm tra ô Restore on exit Always check Restore on exit

Khi duyệt, LAYWALK tạm thời thay đổi trạng thái hiển thị của layer. Giữ ô Restore on exit được tích để AutoCAD trả mọi thứ về như cũ khi bạn đóng hộp thoại.

While walking, LAYWALK temporarily changes layer visibility. Keep Restore on exit ticked so AutoCAD puts everything back when you close the dialog.

Những việc LAYWALK làm rất tốt

What LAYWALK does best

1. Khám phá bản vẽ nhận từ người khác

1. Explore a drawing from someone else

Duyệt lần lượt các layer để biết cấu trúc: layer nào là trục, kích thước, ghi chú, kết cấu... Từ đó bạn dễ quyết định layer nào cần ẩn, khóa hay giữ lại.

Step through the layers to learn the structure: which are grids, dimensions, notes, structure and so on. You can then decide which to hide, lock or keep.

2. Tìm đối tượng lạ hoặc nằm sai layer

2. Find stray objects or objects on the wrong layer

Thấy một đường line hay text không rõ nguồn gốc? Dùng Select Objects để biết nó thuộc layer nào, rồi xem layer đó còn chứa những gì khác. Rất hữu ích khi chuẩn hóa bản vẽ theo tiêu chuẩn layer của công ty.

See a mystery line or text? Use Select Objects to learn its layer, then see what else is on that layer. Very useful when cleaning a drawing to match a company layer standard.

3. Tìm layer trống để dọn

3. Spot empty layers to clean up

Layer nào khi chọn mà màn hình không hiện gì thường là layer trống hoặc chỉ chứa đối tượng ngoài vùng nhìn. Kết hợp với PURGE để xóa layer không dùng. Xem thêm quy trình dọn bản vẽ ở bài giảm dung lượng file DWG.

A layer that shows nothing when selected is usually empty or holds objects outside the current view. Combine this with PURGE to remove unused layers. See the cleanup routine in the guide to reducing DWG size.

LAYWALK khác LAYISO ở điểm nào?

How is LAYWALK different from LAYISO?

  • LAYISO: bạn chọn đối tượng trên bản vẽ, các layer khác bị tắt hoặc khóa và làm mờ. Hợp để tập trung làm việc trên một nhóm đối tượng.LAYISO: you pick objects in the drawing and other layers are turned off or locked and faded. Best for focusing on a group of objects.
  • LAYWALK: bạn chọn layer trong danh sách và xem trực tiếp kết quả. Hợp để khám phá và kiểm tra.LAYWALK: you pick layers from a list and see the result live. Best for exploring and auditing.

So sánh đầy đủ các lệnh quản lý layer ở bài phân biệt LAYISO, LAYOFF, LAYFRZ, LAYLCK, LAYWALK, và cách dùng chi tiết LAYISO ở hướng dẫn LAYISO.

For a full comparison of the layer commands see LAYISO vs LAYOFF, LAYFRZ, LAYLCK and LAYWALK, and for LAYISO in detail see the LAYISO guide.

Nếu layer bị tắt nhầm sau khi dùng

If layers are left off after using it

  • Dùng LAYERP (Layer Previous) để quay về trạng thái layer trước đó.Use LAYERP (Layer Previous) to return to the previous layer state.
  • Gõ LAYON để bật lại tất cả layer đang tắt, và LAYTHW để rã băng tất cả layer đang đóng băng.Type LAYON to turn all layers back on and LAYTHW to thaw every frozen layer.
  • Với bản vẽ hay phải kiểm tra, lưu trước một trạng thái layer bằng LAS (Layer States Manager) để khôi phục chỉ bằng một cú bấm.For drawings you audit often, save a layer state first with LAS (Layer States Manager) so you can restore it in one click.
Lưu ý về phiên bản A note on versions

Lệnh này nằm trong nhóm công cụ Layer Tools. Tùy bản AutoCAD và việc cài đặt Express Tools mà bạn có thể không thấy nó, nhất là trên AutoCAD LT. Nếu gõ lệnh báo Unknown command, hãy kiểm tra Express Tools đã được cài chưa.

This command belongs to the Layer Tools group. Depending on your AutoCAD version and whether Express Tools is installed you may not see it, especially on AutoCAD LT. If it reports Unknown command, check that Express Tools is installed.
