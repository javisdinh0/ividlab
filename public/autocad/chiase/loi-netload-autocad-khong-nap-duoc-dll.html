Các Lỗi NETLOAD Thường Gặp Trong AutoCAD: Không Nạp Được File DLL

Common NETLOAD Errors in AutoCAD: Unable to Load a DLL

Khi dùng NETLOAD nạp plugin .DLL, AutoCAD thường chỉ báo một dòng lỗi dài và khó hiểu. Thực ra phần lớn lỗi thuộc vài nhóm quen thuộc. Hãy đọc kỹ nội dung thông báo ở Command line rồi đối chiếu với các mục dưới đây. Nếu bạn chưa biết cách nạp đúng, xem trước Hướng dẫn NETLOAD.

When you run NETLOAD on a .DLL plugin, AutoCAD often prints a single long, cryptic error. Most failures fall into a few familiar groups. Read the message in the Command line carefully and match it against the sections below. If you are new to the command, start with the NETLOAD guide.

1. "Could not load file or assembly... Operation is not supported (0x80131515)"

1. "Could not load file or assembly... Operation is not supported (0x80131515)"

Đây là lỗi hay gặp nhất với file tải từ Internet hoặc nhận qua email/chat. Windows đánh dấu file là "đến từ máy tính khác" và .NET từ chối nạp nó.

This is the most common error with files downloaded from the Internet or received by email or chat. Windows marks the file as coming from another computer and .NET refuses to load it.

  • Đóng AutoCAD, bấm chuột phải vào file .DLL chọn Properties.Close AutoCAD, right-click the .DLL file and choose Properties.
  • Ở tab General, tích ô Unblock rồi bấm OK.On the General tab tick Unblock and click OK.
  • Nếu plugin có nhiều DLL, hãy Unblock từng file, hoặc giải nén lại từ file ZIP đã được Unblock trước khi giải nén.If the plugin has several DLLs, unblock each one, or unblock the ZIP before extracting it.
  • Mở lại AutoCAD và NETLOAD lại.Reopen AutoCAD and run NETLOAD again.

2. BadImageFormatException: "incorrect format"

2. BadImageFormatException: "incorrect format"

Thông báo kiểu An attempt was made to load a program with an incorrect format nghĩa là file DLL không tương thích với AutoCAD đang chạy. Hai nguyên nhân thường gặp:

A message like An attempt was made to load a program with an incorrect format means the DLL is not compatible with the running AutoCAD. Two usual causes:

  • Sai phiên bản .NET: plugin viết cho .NET Framework (AutoCAD 2024 trở về trước) không nạp được vào AutoCAD dùng .NET mới (AutoCAD 2025 trở đi dùng .NET 8), và ngược lại. Cần bản plugin build đúng cho phiên bản AutoCAD của bạn..NET version mismatch: a plugin written for .NET Framework (AutoCAD 2024 and earlier) will not load in AutoCAD that runs modern .NET (AutoCAD 2025 onward uses .NET 8), and the reverse. You need a build made for your AutoCAD version.
  • Sai kiến trúc: AutoCAD là ứng dụng 64-bit, nên DLL build riêng cho 32-bit (x86) sẽ không nạp được. Plugin cần build ở chế độ x64 hoặc Any CPU.Architecture mismatch: AutoCAD is a 64-bit application, so a DLL built only for 32-bit (x86) will not load. The plugin must be built as x64 or Any CPU.

Cách xử lý: tải đúng bản plugin cho phiên bản AutoCAD của bạn, hoặc liên hệ tác giả để xin bản build phù hợp.

Fix: download the build that matches your AutoCAD version, or ask the author for one.

3. "...or one of its dependencies. The system cannot find the file specified"

3. "...or one of its dependencies. The system cannot find the file specified"

Plugin cần thêm một DLL khác (thư viện đi kèm) nhưng không tìm thấy. Thường do bạn chỉ copy riêng một file DLL ra khỏi thư mục gốc.

The plugin needs another DLL (a companion library) and cannot find it, usually because only one DLL was copied out of the original folder.

  • Giữ nguyên toàn bộ thư mục plugin như bản phát hành, không tách file.Keep the whole plugin folder as released and do not split the files.
  • Đảm bảo các DLL phụ nằm cùng thư mục với file bạn NETLOAD.Make sure companion DLLs sit in the same folder as the file you NETLOAD.
  • Một số plugin cần cài sẵn thành phần như .NET Desktop Runtime hoặc Visual C++ Redistributable; đọc tài liệu đi kèm.Some plugins need a runtime such as the .NET Desktop Runtime or the Visual C++ Redistributable; read the bundled documentation.

4. Nạp xong nhưng không thấy lệnh

4. Loaded, but the command is not found

NETLOAD nạp thành công không đồng nghĩa lệnh có sẵn dưới tên bạn đoán. Tên lệnh do tác giả đặt trong mã. Hãy xem tài liệu của plugin để biết đúng tên. Nếu vẫn báo Unknown command, xem thêm bài về lỗi Unknown command.

A successful NETLOAD does not mean the command exists under the name you guessed. The author defines command names in code, so check the plugin documentation. If you still get Unknown command, see the Unknown command guide.

5. Cảnh báo bảo mật hoặc bị từ chối nạp

5. Security warning or load refused

Nếu thư mục chứa DLL không nằm trong vùng tin cậy, AutoCAD có thể hỏi xác nhận hoặc từ chối hẳn tùy giá trị SECURELOAD. Thêm thư mục vào Trusted Locations theo bài TRUSTEDPATHS & SECURELOAD.

If the DLL folder is not trusted, AutoCAD may ask for confirmation or refuse outright depending on SECURELOAD. Add the folder to Trusted Locations as described in the TRUSTEDPATHS & SECURELOAD guide.

6. Không thay được file DLL mới (file đang bị khóa)

6. You cannot replace the DLL (file is locked)

Sau khi NETLOAD, file DLL bị AutoCAD giữ cho đến khi thoát chương trình, và AutoCAD không có lệnh gỡ nạp. Khi cập nhật plugin hay đang thử bản build mới, Windows sẽ báo file đang được sử dụng. Hãy đóng hẳn AutoCAD (kiểm tra cả Task Manager nếu cần), chép đè file rồi mở lại.

After NETLOAD the DLL stays locked by AutoCAD until you quit, and there is no command to unload it. When updating a plugin or testing a new build, Windows will report the file is in use. Close AutoCAD completely (check Task Manager if needed), overwrite the file and reopen.

7. Mẹo tránh lỗi về sau

7. Tips to avoid problems

  • Đặt plugin ở thư mục cục bộ ổn định, ví dụ C:\CAD Tools\TenPlugin, thay vì thư mục Downloads hoặc ổ mạng.Keep plugins in a stable local folder, for example C:\CAD Tools\PluginName, rather than Downloads or a network drive.
  • Thêm thư mục đó vào Trusted Locations và (nếu cần) vào Startup Suite để tự nạp khi mở AutoCAD.Add that folder to Trusted Locations and, if needed, load it automatically at startup.
  • Ghi lại nguyên văn thông báo lỗi trước khi hỏi tác giả; dòng chứa tên Exception thường đủ để họ xác định nguyên nhân.Copy the exact error text before asking the author; the line naming the Exception is usually enough to pinpoint the cause.
Tóm tắt nhanh Quick summary

Operation is not supported (0x80131515): hãy Unblock. Incorrect format: sai bản .NET hoặc sai kiến trúc. Dependencies: thiếu DLL đi kèm. Không thấy lệnh: kiểm tra tên lệnh. File bị khóa: đóng AutoCAD.

Operation is not supported (0x80131515): unblock the file. Incorrect format: wrong .NET version or architecture. Dependencies: a companion DLL is missing. Command not found: check the command name. File locked: close AutoCAD.
