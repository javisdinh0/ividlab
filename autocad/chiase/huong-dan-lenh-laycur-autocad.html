Hướng Dẫn Lệnh LAYCUR Trong AutoCAD: Chuyển Đối Tượng Sang Layer Hiện Hành

LAYCUR in AutoCAD: Move Objects to the Current Layer

Vẽ xong mới phát hiện cả loạt đường line nằm nhầm layer là chuyện thường gặp. Cách quen thuộc là chọn đối tượng rồi đổi layer trong ô danh sách hoặc bảng Properties, nhưng phải dò tên layer mỗi lần. LAYCUR (Change to Current Layer) làm gọn hơn: bạn đặt layer đúng làm layer hiện hành, rồi chọn các đối tượng cần chuyển sang đó.

Finding out after the fact that a batch of lines sits on the wrong layer is common. The usual fix is to select the objects and change the layer in the dropdown or the Properties palette, but you have to hunt for the layer name each time. LAYCUR (Change to Current Layer) is tidier: make the correct layer current, then select the objects to move onto it.

Cách dùng LAYCUR

How to use LAYCUR

  • Đặt layer đích làm layer hiện hành. Nhanh nhất là gõ LAYMCUR và bấm vào một đối tượng đã nằm đúng layer (xem hướng dẫn LAYMCUR).Make the destination layer current. The fastest way is to type LAYMCUR and click an object already on the right layer (see the LAYMCUR guide).
  • Gõ LAYCUR rồi nhấn Enter.Type LAYCUR and press Enter.
  • Chọn các đối tượng nằm sai layer, nhấn Enter để kết thúc.Select the objects on the wrong layer and press Enter to finish.
  • AutoCAD chuyển các đối tượng đó sang layer hiện hành và báo số lượng đối tượng đã đổi trong Command line.AutoCAD moves those objects to the current layer and reports how many were changed in the Command line.

Ví dụ: bạn lỡ vẽ các đường kích thước phụ lên layer 0. Gõ LAYMCUR, bấm vào một đường kích thước đúng layer, sau đó gõ LAYCUR và quét chọn các đường vẽ nhầm.

Example: you accidentally drew extra dimension lines on layer 0. Type LAYMCUR, click a correctly layered dimension line, then type LAYCUR and window-select the stray lines.

Sửa layer hàng loạt với SELECTSIMILAR

Bulk fixes with SELECTSIMILAR

Khi cần chuyển tất cả đối tượng cùng loại, ví dụ mọi dòng text ghi chú, hãy chọn trước bằng SELECTSIMILAR:

When you need to move every object of one kind, such as all note text, select them first with SELECTSIMILAR:

  • Chọn một đối tượng mẫu (một dòng text), gõ SELECTSIMILAR rồi Enter để chọn tất cả đối tượng giống nó.Pick one sample object (a text line), type SELECTSIMILAR and press Enter to select everything like it.
  • Đặt layer đích làm hiện hành bằng LAYMCUR.Make the destination layer current with LAYMCUR.
  • Gõ LAYCUR. Nếu lệnh nhắc chọn đối tượng, chọn lại bằng cửa sổ hoặc gõ P (Previous) để lấy lại tập chọn vừa tạo.Type LAYCUR. If the command prompts for objects, select again with a window or type P (Previous) to reuse the selection you just made.
Thứ tự thao tác Order of operations

Cách ít sai sót nhất là gõ lệnh LAYCUR trước rồi mới chọn đối tượng ở dòng nhắc, và đọc số lượng đối tượng đã đổi mà AutoCAD báo để chắc chắn không sót.

The least error-prone habit is to type LAYCUR first and then select objects at the prompt, and to read the count of changed objects that AutoCAD reports so you know nothing was missed.

So sánh với các cách đổi layer khác

Compared with other ways to change layers

  • Bảng Properties hoặc ô danh sách layer: linh hoạt nhưng phải tìm tên layer đích trong danh sách dài.Properties palette or layer dropdown: flexible but you must find the destination in a long list.
  • LAYCUR: đích luôn là layer hiện hành; hợp khi bạn đã xác định xong layer đích.LAYCUR: the destination is always the current layer; good once you have settled on the target.
  • LAYMCH: đích là layer của một đối tượng bạn bấm chọn. Không cần đổi layer hiện hành.LAYMCH: the destination is the layer of an object you click. No need to change the current layer.
  • MATCHPROP (lệnh MA): sao chép cả các thuộc tính khác như màu, linetype, ngoài layer.MATCHPROP (command MA): copies other properties such as color and linetype in addition to the layer.
  • LAYMRG: gộp cả layer này vào layer khác và xóa layer nguồn. Xem hướng dẫn LAYMRG.LAYMRG: merges a whole layer into another and deletes the source layer. See the LAYMRG guide.

Lưu ý khi dùng

Things to watch for

  • Đối tượng ByLayer đổi diện mạo: màu, linetype, lineweight đặt ở ByLayer sẽ theo thuộc tính của layer đích, nên hình hiển thị và in có thể khác trước. Kiểm tra lại sau khi chuyển.ByLayer objects change appearance: color, linetype and lineweight set to ByLayer follow the destination layer, so the display and plot can differ. Check the result afterwards.
  • Block: chọn một Block thì lệnh đổi layer của chính Block đó, không đổi layer của các đối tượng bên trong định nghĩa Block.Blocks: selecting a Block changes the Block's own layer, not the layers of objects inside its definition.
  • Layer bị khóa: đối tượng nằm trên layer khóa thường không sửa được; hãy mở khóa trước nếu lệnh không có tác dụng.Locked layers: objects on locked layers usually cannot be changed; unlock first if the command has no effect.
  • Đối tượng của Xref: không thể đổi layer vì thuộc file tham chiếu.Xref objects: their layers cannot be changed because they belong to the referenced file.
  • Dễ hoàn tác: nếu chuyển nhầm, dùng U hoặc Ctrl+Z ngay.Easy to undo: if you moved the wrong things, use U or Ctrl+Z right away.
