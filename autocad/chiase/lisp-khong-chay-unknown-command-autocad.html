Lisp Không Chạy, Báo "Unknown Command" Trong AutoCAD: Nguyên Nhân & Cách Sửa

AutoCAD Lisp Not Running or "Unknown Command": Causes & Fixes

Bạn tải một file Lisp về, nạp vào AutoCAD, gõ lệnh thì nhận được Unknown command. Đây là lỗi gặp nhiều nhất khi mới dùng Lisp, và gần như luôn rơi vào một trong các nguyên nhân dưới đây. Hãy kiểm tra theo thứ tự.

You download a Lisp file, load it into AutoCAD, type the command and get Unknown command. This is the most common beginner problem and it almost always comes down to one of the causes below. Check them in order.

1. File chưa được nạp thành công

1. The file was not actually loaded

Sau khi chọn file trong hộp thoại APPLOAD, bạn phải bấm Load rồi xem dòng thông báo ở cuối hộp thoại và trong Command line. Nếu có chữ loaded successfully hoặc tương tự là file đã nạp. Chỉ chọn file mà chưa bấm Load thì lệnh chưa tồn tại.

After choosing the file in the APPLOAD dialog you must click Load and read the message at the bottom of the dialog and in the Command line. Selecting the file without clicking Load does nothing.

Xem thêm cách làm đúng tại Hướng dẫn APPLOAD & Startup Suite.

See the proper workflow in the APPLOAD & Startup Suite guide.

2. Gõ sai tên lệnh

2. You typed the wrong command name

Tên file không phải là tên lệnh. Lệnh được định nghĩa bên trong file, dạng (defun c:TENLENH (). Mở file .lsp bằng Notepad, tìm các dòng defun c:: phần sau c: chính là lệnh bạn phải gõ. Ví dụ (defun c:MH () thì gõ MH.

The file name is not the command name. The command is defined inside the file as (defun c:COMMANDNAME (). Open the .lsp file in Notepad and search for defun c:; the text after c: is what you type. For example (defun c:MH () means you type MH.

Nếu hàm được khai báo không có tiền tố c: thì nó chỉ gọi được dưới dạng hàm Lisp có ngoặc, ví dụ (tenham), chứ không gõ như một lệnh thường.

If the function is declared without the c: prefix it can only be called as a Lisp function in parentheses, such as (functionname), not typed like a normal command.

Muốn đổi tên lệnh cho dễ nhớ, xem Hướng dẫn tùy chỉnh & đổi tên lệnh AutoLISP.

To rename a command, see How to customize AutoLISP command names.

3. File bị chặn bởi cảnh báo bảo mật

3. The file is blocked by the security setting

Các bản AutoCAD mới có cơ chế an toàn cho việc nạp mã. Nếu thư mục chứa file không nằm trong danh sách tin cậy, AutoCAD có thể hiện cảnh báo hoặc từ chối nạp. Cách xử lý chi tiết ở bài TRUSTEDPATHS & SECURELOAD.

Recent AutoCAD versions restrict code loading. If the folder is not in the trusted list, AutoCAD may warn or refuse to load the file. See the TRUSTEDPATHS & SECURELOAD guide for the fix.

4. File bị lỗi cú pháp hoặc lưu sai định dạng

4. Syntax error or wrong file encoding

  • Thiếu hoặc thừa dấu ngoặc: Command line thường hiện dòng báo lỗi bắt đầu bằng ; error: ngay khi nạp.Missing or extra parentheses: the Command line usually prints an error starting with ; error: as soon as you load.
  • Lưu file bằng Word hoặc trình soạn thảo thêm định dạng: file .lsp phải là văn bản thuần (plain text), nên dùng Notepad.Saving with Word or a rich editor: a .lsp file must be plain text, so use Notepad.
  • Đuôi file bị thành .lsp.txt khi tải về: bật hiển thị phần mở rộng trong Windows để kiểm tra và đổi lại tên.The extension became .lsp.txt after download: show file extensions in Windows and rename it.

5. Lisp phụ thuộc file khác

5. The Lisp depends on another file

Một số bộ Lisp gọi thêm file khác (hàm dùng chung, file dữ liệu, hộp thoại .dcl). Nếu bạn chỉ copy riêng một file ra khỏi bộ thì lệnh có thể nạp được nhưng chạy báo lỗi. Hãy giữ nguyên cả thư mục như bản gốc và thêm thư mục đó vào đường dẫn tìm kiếm của AutoCAD.

Some Lisp packages call other files (shared functions, data files, .dcl dialogs). If you copy a single file out of the set, the command may load but fail when it runs. Keep the whole folder together and add it to AutoCAD's search path.

6. Lisp mất sau khi đóng AutoCAD

6. The Lisp disappears when AutoCAD restarts

Lisp nạp bằng APPLOAD chỉ tồn tại trong phiên làm việc hiện tại. Để tự nạp mỗi lần mở AutoCAD, thêm file vào Startup Suite (nút Contents trong hộp thoại APPLOAD).

Lisp loaded with APPLOAD only lasts for the current session. To load it every time AutoCAD starts, add the file to the Startup Suite (the Contents button in the APPLOAD dialog).

Danh sách kiểm tra nhanh Quick checklist

Đã bấm Load và thấy thông báo thành công? Đã mở file kiểm tra đúng tên defun c:? Thư mục đã nằm trong vùng tin cậy? Không có dòng ; error: khi nạp? Nếu cả bốn đều ổn mà vẫn lỗi, thử mở bản vẽ mới và nạp lại để loại trừ lỗi riêng của bản vẽ.

Did you click Load and see success? Did you check the exact defun c: name? Is the folder trusted? No ; error: line on load? If all four are fine and it still fails, try a new drawing and load again to rule out a drawing-specific problem.
