Hướng Dẫn Tùy Chỉnh & Đổi Tên Lệnh Trong File AutoLISP (.lsp)

Guide to Customize & Rename Commands in AutoLISP (.lsp) Files

Khi tải về các công cụ Lisp hay Plugin cho AutoCAD (như Lisp vẽ xà gồ DrawPurlin của iViDLab), đôi khi tên lệnh mặc định (ví dụ VEXAGO) có thể hơi dài hoặc không thuận tay với thói quen gõ bàn phím của bạn. Hoặc đôi khi lệnh đó bị trùng với một shortcut khác mà bạn đã có trong máy.

When downloading Lisp tools or Plugins for AutoCAD (like iViDLab's DrawPurlin purlin drawing Lisp), sometimes the default command name (e.g., VEXAGO) might be a bit long or not handy for your keyboard typing habits. Or sometimes that command conflicts with another shortcut you already have on your machine.

Bài viết này sẽ hướng dẫn bạn cách tự chỉnh sửa (edit) file .lsp để đổi tên lệnh theo sở thích chỉ với vài thao tác cực kỳ đơn giản và an toàn, không cần phải am hiểu sâu về lập trình AutoLISP.

This article will guide you on how to edit the .lsp file yourself to rename the command to your liking with just a few extremely simple and safe operations, without needing to deeply understand AutoLISP programming.

🖎 Các Bước Đổi Tên Lệnh AutoLISP

🖎 Steps to Rename AutoLISP Commands

Bước 1: Mở tệp tin Lisp (.lsp) bằng trình soạn thảo

Step 1: Open the Lisp file (.lsp) with an editor

Bạn không mở trực tiếp file Lisp bằng AutoCAD để sửa. Thay vào đó, hãy click chuột phải vào file Lisp (ví dụ DrawPurlin.lsp) → Chọn Open with → Chọn Notepad (hoặc nếu có các phần mềm tiện hơn như Notepad++ hay Visual Studio Code thì càng tuyệt vời).

You do not open the Lisp file directly with AutoCAD to edit it. Instead, right-click on the Lisp file (e.g., DrawPurlin.lsp) → Select Open with → Select Notepad (or if you have more convenient software like Notepad++ or Visual Studio Code, that's even better).

Bước 2: Tìm đến cú pháp khai báo tên lệnh

Step 2: Find the command declaration syntax

Trong ngôn ngữ AutoLISP, mọi lệnh có thể gõ trực tiếp trong AutoCAD đều được bắt đầu bằng cú pháp chuẩn:

In the AutoLISP language, every command that can be typed directly in AutoCAD starts with the standard syntax:

(defun c:TEN_LENH () ... )

Trong đó, chữ c: đứng ngay trước tên lệnh là quy ước bắt buộc của AutoCAD (nó tượng trưng cho từ Command, hoàn toàn không liên quan gì đến ổ đĩa C của máy tính cả).

Where the letter c: standing right before the command name is a mandatory convention of AutoCAD (it stands for the word Command, completely unrelated to your computer's C drive).

Hãy bấm tổ hợp phím Ctrl + F trong Notepad và tìm chữ c: hoặc tìm tên lệnh gốc.
Ví dụ trong file DrawPurlin.lsp, bạn sẽ thấy dòng mã như sau:

Press the Ctrl + F key combination in Notepad and search for c: or search for the original command name.
For example, in the DrawPurlin.lsp file, you will see a line of code like this:

(defun c:VEXAGO ( / *error* oldOs oldCmd ... )

Bước 3: Đổi thành tên lệnh bạn yêu thích

Step 3: Change to your favorite command name

Bây giờ, bạn chỉ cần thay đổi cụm từ đi sát sau chữ c: thành tên lệnh ngắn gọn mà bạn muốn dùng.

Now, you just need to change the phrase right after c: to the short command name you want to use.

Ví dụ: Bạn muốn gõ phím XG hoặc VXG cho tiện và siêu nhanh, hãy đổi thành:

For example: You want to type XG or VXG for convenience and super speed, change it to:

(defun c:XG ( / *error* oldOs oldCmd ... )
;; Hoặc:Or:
(defun c:VXG ( / *error* oldOs oldCmd ... )
💡 Mẹo hay: Tạo đồng thời 2 phím tắt cho 1 Lisp 💡 Great tip: Create 2 shortcuts simultaneously for 1 Lisp

Nếu bạn vừa muốn giữ tên lệnh cũ để nhớ thói quen, vừa muốn có thêm tên lệnh siêu ngắn, bạn có thể cuộn xuống cuối cùng của file .lsp và tự tạo một dòng mã bí danh (alias) như sau:
(defun c:XG () (c:VEXAGO))
Khi đó gõ cả VEXAGO hay XG trong CAD đều sẽ cùng chạy một lệnh cho bạn!

If you both want to keep the old command name to remember the habit, and want an additional super short command name, you can scroll to the very bottom of the .lsp file and create an alias code line yourself like this:
(defun c:XG () (c:VEXAGO))
Then typing either VEXAGO or XG in CAD will both run the same command for you!

Bước 4: Lưu file và Tải lại vào AutoCAD

Step 4: Save the file and Reload into AutoCAD

  1. Nhấn Ctrl + S để lưu lại thay đổi (Sau đó có thể đóng Notepad lại). Press Ctrl + S to save the changes (Then you can close Notepad).
  2. Mở bản vẽ AutoCAD của bạn lên, gõ lệnh AP (APPLOAD) → Chọn lại file Lisp bạn vừa chỉnh sửa → Bấm Load. Open your AutoCAD drawing, type the AP (APPLOAD) command → Reselect the Lisp file you just edited → Click Load.
  3. Gõ tên lệnh mới của bạn (ví dụ XG) và trải nghiệm tốc độ vẽ phi thường! Type your new command name (e.g., XG) and experience extraordinary drawing speed!

⚠️ Một Số Lưu Ý Quan Trọng Khi Sửa Code

⚠️ Some Important Notes When Editing Code

1. Tuyệt đối không xóa mất chữ "c:" hay dấu ngoặc đơn 1. Absolutely do not delete the "c:" or parentheses

Nếu bạn lỡ tay sửa thành (defun VEXAGO (mất chữ c:) thì CAD sẽ coi đây là một hàm phụ ẩn và khi ra ngoài giao diện bạn sẽ không thể gõ được tên lệnh này nữa. Đồng thời không làm mất bất kỳ dấu ngoặc đơn ( ) hoặc khoảng trắng nào ở dòng định nghĩa này.

If you accidentally edit it to (defun VEXAGO (losing the c:) then CAD will consider this a hidden sub-function and when returning to the interface you will not be able to type this command name anymore. At the same time, do not lose any parentheses ( ) or spaces in this definition line.

2. Tránh đặt trùng với phím tắt mặc định của AutoCAD 2. Avoid duplicating AutoCAD's default shortcuts

Không nên đặt tên lệnh là L, C, M, CO, PL,... vì nếu trùng lặp, Lisp có thể sẽ ghi đè và làm vô hiệu hóa các lệnh cơ bản như Line, Circle, Move hay Polyline của bạn khi file Lisp đang được nạp.

You should not name the command L, C, M, CO, PL,... because if duplicated, the Lisp might overwrite and disable your basic commands like Line, Circle, Move or Polyline while the Lisp file is loaded.

3. Lưu file ở định dạng mã hóa (Encoding) đúng 3. Save the file in the correct Encoding format

Khi lưu bằng Notepad, hãy chắc chắn chọn Encoding là UTF-8 (hoặc ANSI) và không để bị tự động đổi đuôi tệp thành .lsp.txt.

When saving with Notepad, make sure to select Encoding as UTF-8 (or ANSI) and do not let it automatically change the file extension to .lsp.txt.
