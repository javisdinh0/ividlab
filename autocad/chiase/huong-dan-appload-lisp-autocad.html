Hướng Dẫn APPLOAD & Startup Suite Tải Lisp Tự Động Vào AutoCAD

Guide to APPLOAD & Startup Suite for Automatic Lisp Loading in AutoCAD

Khi sử dụng AutoCAD trong thiết kế và xây dựng, việc sử dụng AutoLISP (hoặc các tiện ích ObjectARX, VBA) là bí quyết cốt lõi để nâng cao năng suất vẽ và tự động hóa thao tác. Để các tệp tin này hoạt động, bạn cần phải nạp chúng vào bộ nhớ của AutoCAD thông qua lệnh APPLOAD (hoặc gõ tắt là AP).

When using AutoCAD in design and construction, utilizing AutoLISP (or ObjectARX, VBA utilities) is the core secret to enhancing drawing productivity and automating operations. For these files to work, you need to load them into AutoCAD's memory via the APPLOAD command (or its shortcut AP).

Bài viết này sẽ hướng dẫn bạn hai phương pháp: Tải tạm thời cho phiên làm việc hiện tại và Thiết lập Startup Suite (Add Contents) để Lisp tự động chạy mãi mãi mỗi lần mở AutoCAD mà không phải load lại hằng ngày.

This article will guide you through two methods: Temporary loading for the current session and Setting up Startup Suite (Add Contents) to make Lisp run automatically forever every time you open AutoCAD without reloading it daily.

📂 Phương Pháp 1: Nạp Lisp Cho Phiên Làm Việc Hiện Tại

📂 Method 1: Loading Lisp for the Current Session

Phương pháp này phù hợp khi bạn muốn dùng thử một công cụ Lisp mới tải về hoặc chỉ có nhu cầu sử dụng tạm thời trong ngày:

This method is suitable when you want to try out a newly downloaded Lisp tool or only need to use it temporarily for the day:

  1. Trong màn hình làm việc AutoCAD, gõ lệnh AP (hoặc APPLOAD) rồi nhấn Enter hoặc Space. In the AutoCAD workspace, type the command AP (or APPLOAD) then press Enter or Space.
  2. Hộp thoại Load/Unload Applications xuất hiện. Tại khung duyệt file phía trên, bạn tìm đến thư mục chứa file cần nạp (hỗ trợ các đuôi .lsp, .fas, .vlx, .arx, .crx, .dvb...). The Load/Unload Applications dialog box appears. In the file browsing frame above, navigate to the folder containing the file to be loaded (supports extensions .lsp, .fas, .vlx, .arx, .crx, .dvb...).
  3. Chọn file (ví dụ DrawPurlin.lsp) và bấm nút Load ở giữa hộp thoại. Select the file (e.g., DrawPurlin.lsp) and click the Load button in the middle of the dialog.
  4. Quan sát góc dưới bên trái của hộp thoại. Nếu thấy dòng thông báo "DrawPurlin.lsp successfully loaded." nghĩa là bạn đã nạp thành công! Observe the bottom left corner of the dialog. If you see the message "DrawPurlin.lsp successfully loaded.", it means you have loaded it successfully!
  5. Bấm Close để đóng hộp thoại và bắt đầu gõ lệnh Lisp (ví dụ VEXAGO) để sử dụng ngay. Click Close to close the dialog and start typing the Lisp command (e.g., VEXAGO) to use immediately.
💡 Mẹo nhanh: Kéo và thả trực tiếp (Drag & Drop) 💡 Quick Tip: Drag & Drop directly

Cách nạp siêu nhanh mà các kỹ sư thành thạo thường dùng là Mở thư mục Windows Explorer chứa file Lisp bên cạnh màn hình CAD, sau đó nhấp giữ chuột vào file Lisp, kéo thẳng và thả vào vùng không gian vẽ (Drawing Area) của AutoCAD. Lisp sẽ lập tức được nạp mà không cần bật hộp thoại AP!

An ultra-fast loading method often used by proficient engineers is to open the Windows Explorer folder containing the Lisp file next to the CAD screen, then click and hold the Lisp file, drag it straight and drop it into the drawing area of AutoCAD. The Lisp will immediately be loaded without opening the AP dialog!

🚀 Phương Pháp 2: Thiết Lập Startup Suite (Tự Động Nạp Khi Mở CAD)

🚀 Method 2: Setting up Startup Suite (Auto Load on CAD Start)

Nếu bạn có những tiện ích AutoLISP thường xuyên sử dụng hàng ngày trong công việc, việc thao tác gõ lệnh AP và tải file thủ công mỗi lần khởi động AutoCAD sẽ bất tiện và tốn thời gian. Bạn có thể tận dụng tính năng Startup Suite để tự động hóa quá trình này:

If you have AutoLISP utilities frequently used daily in your work, manually typing the AP command and loading files each time you start AutoCAD will be inconvenient and time-consuming. You can utilize the Startup Suite feature to automate this process:

  1. Gõ lệnh AP (hoặc APPLOAD) và nhấn Space để mở hộp thoại Load/Unload Applications. Type the AP (or APPLOAD) command and press Space to open the Load/Unload Applications dialog box.
  2. Quan sát mục Startup Suite ở góc bên dưới bên phải hộp thoại. Bấm vào nút Contents... ngay bên cạnh. Observe the Startup Suite section in the lower right corner of the dialog. Click the Contents... button right next to it.
  3. Hộp thoại Startup Suite xuất hiện, hiển thị danh sách các tiện ích đã được đăng ký nạp tự động. Bạn tiếp tục bấm nút Add... ở góc dưới. The Startup Suite dialog box appears, displaying the list of utilities registered for automatic loading. Continue by clicking the Add... button at the bottom.
  4. Duyệt tìm trên ổ đĩa, chọn các file .lsp, .fas hoặc .vlx cần nạp rồi bấm Open. Browse on your drive, select the .lsp, .fas, or .vlx files to load and click Open.
  5. Tệp tin sẽ xuất hiện trong danh sách Startup Suite. Bạn bấm Close để chốt cài đặt, sau đó đóng hộp thoại APPLOAD. The files will appear in the Startup Suite list. Click Close to confirm the settings, then close the APPLOAD dialog.

✨ Kết quả: ✨ Result: Từ thời điểm này, mỗi khi bạn khởi động AutoCAD hoặc tạo bản vẽ mới, phần mềm sẽ ngầm tải sẵn các công cụ trong danh sách này vào bộ nhớ. Bạn có thể sử dụng ngay lập tức các phím tắt của Lisp mà không cần tải lại thủ công! From this point on, whenever you start AutoCAD or create a new drawing, the software will silently preload the tools in this list into memory. You can immediately use the Lisp shortcuts without reloading manually!

⚠️ Các Lưu Ý Khi Thiết Lập Startup Suite

⚠️ Notes When Setting Up Startup Suite

1. Không thay đổi vị trí lưu trữ file Lisp sau khi đã thêm vào danh sách 1. Do not change the Lisp file location after adding it to the list

Startup Suite ghi nhớ đường dẫn cố định (Absolute Path) tới file trên máy tính. Nếu sau khi cấu hình, bạn chuyển file sang thư mục khác, thay đổi ký tự ổ đĩa hoặc đổi tên tệp, AutoCAD sẽ báo lỗi "Unable to load..." ở lần mở CAD tiếp theo vì không còn tìm thấy file theo đường dẫn cũ.

Startup Suite remembers the absolute path to the file on the computer. If after configuring, you move the file to another folder, change the drive letter, or rename the file, AutoCAD will report an "Unable to load..." error the next time CAD opens because it can no longer find the file using the old path.

2. Lưu file ở vị trí cố định, không để khoảng trắng hay Tiếng Việt có dấu 2. Save files in a fixed location, avoid spaces or Vietnamese accents

Bạn nên lập một thư mục cố định trên đĩa cứng (ví dụ D:\CAD_Tools\AutoLISP\ hoặc C:\iViDLab_Tools\) chuyên dụng để quản lý tiện ích. Tránh lưu tệp trong đĩa ảo, thư mục tạm Downloads hoặc các đường dẫn chứa ký tự Tiếng Việt có dấu hoặc ký tự đặc biệt, nhằm bảo đảm AutoCAD đọc và thực thi chuỗi đường dẫn mượt mà không xung đột mã phông chữ.

You should create a fixed folder on your hard drive (e.g., D:\CAD_Tools\AutoLISP\ or C:\iViDLab_Tools\) dedicated to managing utilities. Avoid saving files in virtual drives, temporary Downloads folders, or paths containing Vietnamese accents or special characters to ensure AutoCAD reads and executes the path string smoothly without font encoding conflicts.

3. Chỉ đưa các tiện ích thiết yếu vào Startup Suite 3. Only add essential utilities to Startup Suite

Tránh thêm quá nhiều file công cụ không thường dùng (ví dụ hàng chục file Lisp rải rác) vào Startup Suite vì điều này có thể làm ảnh hưởng đến tốc độ khởi động của AutoCAD.

Avoid adding too many infrequently used tool files (e.g., dozens of scattered Lisp files) to Startup Suite as this can affect AutoCAD's startup speed.
