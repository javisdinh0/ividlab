Cảnh Báo Bảo Mật Khi Nạp Lisp/DLL Trong AutoCAD: TRUSTEDPATHS & SECURELOAD

Security Warning When Loading Lisp/DLL in AutoCAD: TRUSTEDPATHS & SECURELOAD

Khi nạp Lisp hoặc DLL từ một thư mục lạ, AutoCAD có thể hiện hộp thoại cảnh báo bảo mật hoặc từ chối nạp. Đó là cơ chế bảo vệ do hai biến hệ thống SECURELOAD và TRUSTEDPATHS điều khiển. Bài này giải thích chúng và cách thiết lập để công cụ của bạn chạy mượt mà mà vẫn an toàn.

When you load Lisp or DLL files from an unfamiliar folder, AutoCAD may show a security warning or refuse to load. This protection is controlled by two system variables, SECURELOAD and TRUSTEDPATHS. This guide explains them and how to configure them safely.

SECURELOAD là gì?

What is SECURELOAD?

SECURELOAD quyết định AutoCAD xử lý thế nào với file thực thi (Lisp, ARX, DLL...) nằm ngoài vùng tin cậy:

SECURELOAD decides how AutoCAD treats executable files (Lisp, ARX, DLL...) located outside trusted folders:

  • 0: nạp từ mọi nơi và không cảnh báo (kém an toàn nhất).0: load from anywhere with no warning (least safe).
  • 1: nạp thẳng từ vùng tin cậy, còn ngoài vùng tin cậy thì hỏi bạn có cho phép không.1: load directly from trusted folders and prompt you for anything outside them.
  • 2: chỉ nạp từ vùng tin cậy, các nơi khác bị từ chối.2: load only from trusted folders; everything else is refused.

Giá trị mặc định có thể khác nhau tùy phiên bản AutoCAD. Gõ SECURELOAD trong Command line để xem giá trị hiện tại trên máy bạn.

The default value can vary by AutoCAD version. Type SECURELOAD in the Command line to see the current value on your machine.

Cách thêm thư mục vào vùng tin cậy

How to add a folder to the trusted list

Cách 1: qua hộp thoại Options

Method 1: via the Options dialog

  • Gõ OP và nhấn Enter để mở Options.Type OP and press Enter to open Options.
  • Chọn tab Files, mở mục Trusted Locations.Go to the Files tab and expand Trusted Locations.
  • Chọn Add rồi Browse tới thư mục chứa Lisp/DLL của bạn.Choose Add, then Browse to the folder containing your Lisp/DLL files.
  • Bấm OK. Từ lần nạp sau, file trong thư mục này sẽ không bị cảnh báo.Click OK. Files in this folder will no longer trigger a warning.

Cách 2: qua biến TRUSTEDPATHS

Method 2: via the TRUSTEDPATHS variable

Gõ TRUSTEDPATHS rồi nhập danh sách thư mục, ngăn cách bằng dấu chấm phẩy. Thêm ... ở cuối đường dẫn để bao gồm cả thư mục con:

Type TRUSTEDPATHS and enter the folder list, separated by semicolons. Add ... at the end of a path to include its subfolders:

C:\Lisp;D:\CAD Tools\...

C:\Lisp;D:\CAD Tools\...

Lưu ý: khi nhập biến, nhớ giữ lại các đường dẫn đã có sẵn, nếu không bạn sẽ ghi đè mất chúng.

Note: when you set the variable, keep the paths that are already there, otherwise you will overwrite them.

Nên đặt thư mục nào làm tin cậy?

Which folders should be trusted?

  • Chỉ thêm thư mục chứa công cụ bạn biết rõ nguồn gốc, ví dụ thư mục cài đặt Lisp/plugin của riêng bạn.Only add folders holding tools whose source you know, such as your own Lisp or plugin folder.
  • Không thêm cả ổ đĩa (C:\) hoặc thư mục Downloads, vì file tải về bất kỳ cũng sẽ được tin cậy.Do not add a whole drive (C:\) or your Downloads folder, because any downloaded file would then be trusted.
  • Đừng hạ SECURELOAD xuống 0 chỉ để hết cảnh báo; thêm đúng thư mục vào vùng tin cậy sẽ an toàn hơn.Do not set SECURELOAD to 0 just to silence the warning; trusting the right folder is safer.
Với file DLL tải từ Internet For DLL files downloaded from the Internet

Ngoài vùng tin cậy, Windows còn có thể đánh dấu file tải về là bị chặn. Hãy bấm chuột phải vào file, chọn Properties và tích Unblock trước khi dùng NETLOAD. Chi tiết tại Hướng dẫn NETLOAD.

Besides trusted folders, Windows may also mark downloaded files as blocked. Right-click the file, open Properties and tick Unblock before using NETLOAD. Details in the NETLOAD guide.
