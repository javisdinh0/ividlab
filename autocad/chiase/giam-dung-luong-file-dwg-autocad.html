Cách Giảm Dung Lượng File DWG Nặng Và Làm AutoCAD Chạy Nhanh Hơn

How to Reduce a Heavy DWG File Size and Speed Up AutoCAD

File DWG nặng làm AutoCAD mở lâu, zoom giật và dễ treo. Nguyên nhân thường không phải do bản vẽ "to" mà do dữ liệu thừa tích lũy qua thời gian: block, layer, style không dùng, đối tượng trùng lặp, dữ liệu lỗi. Dưới đây là quy trình dọn theo thứ tự nên làm.

A heavy DWG makes AutoCAD slow to open, laggy when zooming and prone to crashing. The cause is usually not the drawing size itself but leftover data that builds up over time: unused blocks, layers and styles, duplicate objects, corrupted data. Here is a cleanup routine in a sensible order.

Làm trước khi dọn Before you clean

Luôn lưu một bản sao của file gốc trước khi dọn. Một số bước (đặc biệt là PURGE tất cả và OVERKILL) xóa dữ liệu mà bạn không thể hoàn tác sau khi đã lưu.

Always save a copy of the original file first. Some steps (especially purging everything and OVERKILL) remove data that cannot be undone after you save.

Bước 1: PURGE các đối tượng không dùng

Step 1: PURGE unused objects

Gõ PURGE (hoặc PU), chọn các nhóm cần dọn như block, layer, linetype, text style, dimension style rồi bấm Purge All. Lệnh này xóa các định nghĩa không còn được sử dụng. Có thể cần chạy lặp lại 2 đến 3 lần vì xóa xong nhóm này lại làm lộ ra nhóm khác chưa dùng.

Type PURGE (or PU), select the groups to clean, such as blocks, layers, linetypes, text styles and dimension styles, then click Purge All. It removes definitions that are no longer used. You may need to run it two or three times because removing one group exposes others that are now unused.

Bước 2: AUDIT để sửa lỗi dữ liệu

Step 2: AUDIT to fix data errors

Gõ AUDIT và chọn Yes để sửa lỗi phát hiện được. Dữ liệu lỗi có thể làm file phình to hoặc chạy chậm bất thường. Nếu file không mở được, thử lệnh RECOVER thay cho mở thông thường.

Type AUDIT and choose Yes to fix any errors found. Corrupted data can bloat a file or slow it down. If the file will not open, try RECOVER instead of a normal open.

Bước 3: OVERKILL xóa đối tượng trùng

Step 3: OVERKILL to remove duplicates

Gõ OVERKILL, chọn toàn bộ bản vẽ. Lệnh sẽ xóa các đối tượng trùng nhau hoặc chồng lên nhau (đường line, arc, polyline vẽ đè cùng vị trí). Bản vẽ nhập từ nhiều nguồn hoặc copy nhiều lần thường có rất nhiều đối tượng loại này. Nên xem lại hộp thoại tùy chọn trước khi chạy để không gộp những thứ bạn muốn giữ.

Type OVERKILL and select the whole drawing. It deletes duplicate or overlapping objects (lines, arcs and polylines drawn on top of each other). Drawings merged from several sources or copied many times often contain plenty of these. Review the options dialog first so you do not merge things you want to keep.

Bước 4: Kiểm tra Xref, ảnh và đối tượng tham chiếu

Step 4: Check Xrefs, images and references

  • Mở XREF (Xref Manager) để gỡ bỏ Xref không dùng, tránh Xref bị mất đường dẫn.Open XREF (Xref Manager) and detach unused Xrefs, and avoid Xrefs with broken paths.
  • Với ảnh nền (raster) lớn, cân nhắc giảm kích thước ảnh hoặc dùng đường dẫn tương đối.For large raster images, consider shrinking them or using relative paths.
  • Hạn chế chèn bản vẽ khác bằng INSERT nguyên cả file vì kéo theo toàn bộ dữ liệu của file đó; dùng WBLOCK để chỉ xuất phần cần thiết.Avoid inserting whole drawings with INSERT, since all of that file's data comes along; use WBLOCK to export only what you need.

Bước 5: WBLOCK sang file mới

Step 5: WBLOCK into a fresh file

Đây là cách hiệu quả khi các bước trên chưa đủ. Gõ WBLOCK, chọn Objects hoặc toàn bộ đối tượng cần giữ, đặt tên file mới và lưu. File mới chỉ chứa phần bạn chọn nên thường nhẹ hơn rõ rệt so với bản gốc đã tích lũy dữ liệu thừa. Kiểm tra lại layer, style và layout trong file mới trước khi thay thế file cũ.

This helps when the steps above are not enough. Type WBLOCK, select Objects (or everything you want to keep), name the new file and save. The new file contains only what you selected, so it is often noticeably lighter than the original that accumulated leftover data. Check layers, styles and layouts in the new file before replacing the old one.

Mẹo giữ file nhẹ về lâu dài

Habits that keep files light

  • Dọn PURGE định kỳ, không chờ đến lúc file nặng mới làm.Run PURGE regularly instead of waiting until the file is heavy.
  • Tránh copy bản vẽ từ các file cũ chứa nhiều rác sang bản vẽ mới bằng Ctrl+C; hãy dọn nguồn trước.Avoid copying from old, cluttered drawings into new ones with Ctrl+C; clean the source first.
  • Dùng layer hợp lý, không tạo hàng trăm layer thừa từ bản vẽ nhập về.Use layers sensibly and do not import hundreds of unused layers.
  • Nên dùng LAYISO để cô lập layer khi thao tác, giúp làm việc trên bản vẽ lớn dễ hơn.Use LAYISO to isolate layers while working, which makes large drawings easier to handle.
