Hướng Dẫn NETLOAD Nạp Plugin (.DLL) Trong AutoCAD

Guide to NETLOAD for Loading Plugins (.DLL) in AutoCAD

Bên cạnh ngôn ngữ AutoLISP quen thuộc, khi lập trình các ứng dụng tự động hóa xây dựng quy mô lớn (BIM Workflow, trao đổi dữ liệu qua API, các công cụ phân tích kết cấu như PEB Section Creator), các lập trình viên thường phát triển bằng ngôn ngữ C# hoặc VB.NET trên nền tảng .NET của Microsoft. Sản phẩm khi biên dịch ra sẽ đóng gói thành tệp tin thư viện động có đuôi .dll (Managed Assembly).

Besides the familiar AutoLISP language, when programming large-scale construction automation applications (BIM Workflow, data exchange via API, structural analysis tools like PEB Section Creator), programmers often develop using C# or VB.NET on Microsoft's .NET platform. The compiled product is packaged into a dynamic link library file with a .dll extension (Managed Assembly).

Để nạp các Plugin loại này vào AutoCAD và sử dụng lệnh, chúng ta không dùng APPLOAD thông thường mà phải sử dụng lệnh đặc biệt là NETLOAD.

To load these types of Plugins into AutoCAD and use their commands, we do not use the standard APPLOAD but must use a special command: NETLOAD.

🖇 Các Bước Thực Hiện NETLOAD Trong AutoCAD

🖇 Steps to Execute NETLOAD in AutoCAD

  1. Mở bản vẽ AutoCAD của bạn lên. Tại dòng nhắc lệnh (Command line), nhập từ khóa NETLOAD và nhấn Enter hoặc Space. Open your AutoCAD drawing. At the command line, type the keyword NETLOAD and press Enter or Space.
  2. Hộp thoại Choose .NET Assembly (Chọn tệp DLL) lập tức xuất hiện trên màn hình. The Choose .NET Assembly dialog box will immediately appear on the screen.
  3. Duyệt tìm đến thư mục trên ổ cứng nơi bạn lưu trữ file .dll của Plugin cần chạy. Browse to the folder on your hard drive where you stored the .dll file of the Plugin you need to run.
  4. Nhấn chọn file .dll và bấm nút Open. Select the .dll file and click the Open button.
  5. Sau khi tệp nạp vào bộ nhớ (không hiển thị thêm lỗi gì), toàn bộ bộ lệnh mới do Plugin đó cung cấp đã sẵn sàng. Bạn chỉ cần gõ tên lệnh custom của DLL vào thanh Command để kích hoạt! After the file is loaded into memory (without showing any errors), the entire new command set provided by that Plugin is ready. You just need to type the custom command name of the DLL into the Command bar to activate it!

⚠️ Thao Tác Bắt Buộc: UNBLOCK File DLL Tải Từ Internet

⚠️ Mandatory Action: UNBLOCK DLL Files Downloaded from the Internet

Đây là nguyên nhân số 1 khiến 90% kỹ sư gặp lỗi "Cannot load assembly..." hoặc Plugin từ chối chạy khi tải các file .dll từ Internet hay email về máy tính. Hệ điều hành Windows mặc định khóa bảo mật đối với các tệp thực thi tải từ bên ngoài!

This is the #1 reason why 90% of engineers encounter the "Cannot load assembly..." error or the Plugin refuses to run when downloading .dll files from the Internet or email to their computers. The Windows operating system locks security by default for executable files downloaded from outside sources!

🔓 Hướng dẫn Mở Khóa (Unblock) File DLL trước khi NETLOAD: 🔓 Guide to Unblock DLL Files before NETLOAD:

1. Trước khi mở CAD, mở thư mục chứa file .dll vừa tải về.
2. Click chuột phải thẳng vào file DLL → Chọn Properties (Thuộc tính nằm cuối cùng).
3. Ở tab General, nhìn xuống phía góc dưới cùng bên phải, nếu có mục Security: This file came from another computer... thì hãy Tích VÀO ô Unblock (hoặc bấm nút Unblock tùy phiên bản Windows).
4. Bấm Apply rồi OK. Lúc này bạn mới vào AutoCAD gõ NETLOAD nạp file thành công!

1. Before opening CAD, open the folder containing the recently downloaded .dll file.
2. Right-click directly on the DLL file → Select Properties (located at the bottom).
3. In the General tab, look down at the bottom right corner, if there is a Security: This file came from another computer... section, then Check the Unblock box (or click the Unblock button depending on Windows version).
4. Click Apply then OK. Now you can go into AutoCAD and type NETLOAD to load the file successfully!

📜 Sự Khác Biệt Quan Trọng: Hiện Tượng Khóa Tệp (File Lock)

📜 Important Difference: File Lock Phenomenon

🔒 Tại sao không thể ghi đè, xóa hoặc sửa file .DLL khi đang chạy CAD? 🔒 Why can't you overwrite, delete or modify a .DLL file while CAD is running?

Trong kiến trúc .NET Framework của AutoCAD, một khi file .dll đã nạp vào bằng lệnh NETLOAD, hệ thống AutoCAD sẽ khóa chết (lock) tệp tin đó trong bộ nhớ RAM của phiên làm việc. Bạn không thể nạp lại (Reload) cùng 1 file, không thể dùng lệnh AP để unload và cũng không thể xóa hay ghi đè file mới ở thư mục nguồn.

In AutoCAD's .NET Framework architecture, once a .dll file is loaded using the NETLOAD command, the AutoCAD system will lock that file in the RAM memory of the session. You cannot reload the same file, cannot use the AP command to unload it, and cannot delete or overwrite the new file in the source folder.

👉 Cách tháo gỡ: Để cập nhật phiên bản DLL mới hoặc biên dịch (Build) lại code C# trong Visual Studio, bạn bắt buộc phải tắt hẳn ứng dụng AutoCAD rồi mở lại, hoặc các dev có thể cấu hình tải qua cơ chế Shadow Copy trong tệp cấu hình CAD. 👉 Workaround: To update a new DLL version or recompile (Build) C# code in Visual Studio, you must completely close the AutoCAD application and open it again, or developers can configure loading via the Shadow Copy mechanism in the CAD config file.

🔑 Cấu Hình Biến Bảo Mật (SECURELOAD & Trusted Locations)

🔑 Security Variable Configuration (SECURELOAD & Trusted Locations)

Từ các phiên bản AutoCAD mới hiện nay (2016 trở lên), cơ chế bảo mật của AutoCAD được siết chặt đối với tệp tin mã lệnh từ bên ngoài. Nếu khi dùng lệnh NETLOAD xuất hiện bảng cảnh báo "Security Concern: You are about to run an executable file...", bạn có thể thiết lập như sau:

In recent newer versions of AutoCAD (2016 and above), AutoCAD's security mechanism is tightened against external code files. If when using the NETLOAD command a warning box appears saying "Security Concern: You are about to run an executable file...", you can configure it as follows:

  • Thêm Thư Mục Tin Cậy (Trusted Locations): Add Trusted Locations: Gõ lệnh OP (Options) → Mở tab Files → Mở rộng nhánh Trusted Locations → Bấm Add rồi chỉ đường dẫn tới thư mục lưu Lisp & Plugin trên đĩa cứng của bạn. Từ thời điểm này, mọi tệp nạp từ các thư mục trong danh sách tin cậy sẽ được AutoCAD chạy tự động và không hiện cảnh báo. Type the command OP (Options) → Open the Files tab → Expand the Trusted Locations branch → Click Add then point the path to the folder saving Lisp & Plugins on your hard drive. From this point on, any files loaded from folders in the trusted list will be automatically run by AutoCAD without displaying warnings.
  • Tùy chỉnh biến hệ thống SECURELOAD: Customize the SECURELOAD system variable: Gõ lệnh SECURELOAD vào thanh Command. Nhập giá trị 0 (Tắt cảnh báo nạp code) hoặc giữ mức mặc định 1 (Chỉ tự động nạp mà không cảnh báo nếu file nằm trong Trusted Locations). Type the SECURELOAD command into the Command bar. Enter the value 0 (Turn off code load warnings) or keep the default level 1 (Only automatically load without warnings if the file is in Trusted Locations).
