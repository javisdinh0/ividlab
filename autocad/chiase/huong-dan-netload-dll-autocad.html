Hướng Dẫn NETLOAD Nạp Plugin (.DLL) Trong AutoCAD

Bên cạnh ngôn ngữ AutoLISP quen thuộc, khi lập trình các ứng dụng tự động hóa xây dựng quy mô lớn (BIM Workflow, trao đổi dữ liệu qua API, các công cụ phân tích kết cấu như PEB Section Creator), các lập trình viên thường phát triển bằng ngôn ngữ C# hoặc VB.NET trên nền tảng .NET của Microsoft. Sản phẩm khi biên dịch ra sẽ đóng gói thành tệp tin thư viện động có đuôi .dll (Managed Assembly).

Để nạp các Plugin loại này vào AutoCAD và sử dụng lệnh, chúng ta không dùng APPLOAD thông thường mà phải sử dụng lệnh đặc biệt là NETLOAD.

🖇 Các Bước Thực Hiện NETLOAD Trong AutoCAD

  1. Mở bản vẽ AutoCAD của bạn lên. Tại dòng nhắc lệnh (Command line), nhập từ khóa NETLOAD và nhấn Enter hoặc Space.
  2. Hộp thoại Choose .NET Assembly (Chọn tệp DLL) lập tức xuất hiện trên màn hình.
  3. Duyệt tìm đến thư mục trên ổ cứng nơi bạn lưu trữ file .dll của Plugin cần chạy.
  4. Nhấn chọn file .dll và bấm nút Open.
  5. Sau khi tệp nạp vào bộ nhớ (không hiển thị thêm lỗi gì), toàn bộ bộ lệnh mới do Plugin đó cung cấp đã sẵn sàng. Bạn chỉ cần gõ tên lệnh custom của DLL vào thanh Command để kích hoạt!

⚠️ Thao Tác Bắt Buộc: UNBLOCK File DLL Tải Từ Internet

Đây là nguyên nhân số 1 khiến 90% kỹ sư gặp lỗi "Cannot load assembly..." hoặc Plugin từ chối chạy khi tải các file .dll từ Internet hay email về máy tính. Hệ điều hành Windows mặc định khóa bảo mật đối với các tệp thực thi tải từ bên ngoài!

🔓 Hướng dẫn Mở Khóa (Unblock) File DLL trước khi NETLOAD:

1. Trước khi mở CAD, mở thư mục chứa file .dll vừa tải về.
2. Click chuột phải thẳng vào file DLL → Chọn Properties (Thuộc tính nằm cuối cùng).
3. Ở tab General, nhìn xuống phía góc dưới cùng bên phải, nếu có mục Security: This file came from another computer... thì hãy Tích VÀO ô Unblock (hoặc bấm nút Unblock tùy phiên bản Windows).
4. Bấm Apply rồi OK. Lúc này bạn mới vào AutoCAD gõ NETLOAD nạp file thành công!

📜 Sự Khác Biệt Quan Trọng: Hiện Tượng Khóa Tệp (File Lock)

🔒 Tại sao không thể ghi đè, xóa hoặc sửa file .DLL khi đang chạy CAD?

Trong kiến trúc .NET Framework của AutoCAD, một khi file .dll đã nạp vào bằng lệnh NETLOAD, hệ thống AutoCAD sẽ khóa chết (lock) tệp tin đó trong bộ nhớ RAM của phiên làm việc. Bạn không thể nạp lại (Reload) cùng 1 file, không thể dùng lệnh AP để unload và cũng không thể xóa hay ghi đè file mới ở thư mục nguồn.

👉 Cách tháo gỡ: Để cập nhật phiên bản DLL mới hoặc biên dịch (Build) lại code C# trong Visual Studio, bạn bắt buộc phải tắt hẳn ứng dụng AutoCAD rồi mở lại, hoặc các dev có thể cấu hình tải qua cơ chế Shadow Copy trong tệp cấu hình CAD.

🔑 Cấu Hình Biến Bảo Mật (SECURELOAD & Trusted Locations)

Từ các phiên bản AutoCAD mới hiện nay (2016 trở lên), cơ chế bảo mật của AutoCAD được siết chặt đối với tệp tin mã lệnh từ bên ngoài. Nếu khi dùng lệnh NETLOAD xuất hiện bảng cảnh báo "Security Concern: You are about to run an executable file...", bạn có thể thiết lập như sau:

  • Thêm Thư Mục Tin Cậy (Trusted Locations): Gõ lệnh OP (Options) → Mở tab Files → Mở rộng nhánh Trusted Locations → Bấm Add rồi chỉ đường dẫn tới thư mục lưu Lisp & Plugin trên đĩa cứng của bạn. Từ thời điểm này, mọi tệp nạp từ các thư mục trong danh sách tin cậy sẽ được AutoCAD chạy tự động và không hiện cảnh báo.
  • Tùy chỉnh biến hệ thống SECURELOAD: Gõ lệnh SECURELOAD vào thanh Command. Nhập giá trị 0 (Tắt cảnh báo nạp code) hoặc giữ mức mặc định 1 (Chỉ tự động nạp mà không cảnh báo nếu file nằm trong Trusted Locations).

Tài liệu được tổng hợp và biên soạn bởi đội ngũ kỹ thuật iViDLab.com.
