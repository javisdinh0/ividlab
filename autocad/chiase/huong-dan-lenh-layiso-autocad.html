Hướng dẫn toàn tập về lệnh LAYISO trong AutoCAD

Comprehensive Guide to the LAYISO Command in AutoCAD

LAYISO (viết tắt của Layer Isolate) là một trong những lệnh quản lý Layer quan trọng và được sử dụng thường xuyên nhất trong AutoCAD. Lệnh này giúp người dùng tối ưu hóa không gian làm việc bằng cách cô lập các đối tượng cần thiết, từ đó giúp việc quan sát, bắt điểm và chỉnh sửa bản vẽ trở nên dễ dàng và chính xác hơn.

LAYISO (stands for Layer Isolate) is one of the most important and frequently used Layer management commands in AutoCAD. This command helps users optimize the workspace by isolating necessary objects, thereby making viewing, snapping, and editing drawings easier and more accurate.

Bài viết dưới đây sẽ hướng dẫn bạn cách sử dụng cơ bản lệnh LAYISO, cách khôi phục Layer, và đặc biệt là cách thiết lập chế độ hiển thị (ẩn đi hoặc làm mờ) cho lệnh này.

The article below will guide you on the basic use of the LAYISO command, how to restore Layers, and especially how to set the display mode (hide or fade) for this command.

1. Cách sử dụng lệnh LAYISO cơ bản

1. How to use the basic LAYISO command

Chức năng chính của LAYISO là giữ lại (cô lập) layer của đối tượng được chọn và xử lý các layer còn lại (ẩn đi hoặc làm mờ).

The main function of LAYISO is to keep (isolate) the layer of the selected object and process the remaining layers (hide or fade them).

Các bước thực hiện:Steps to execute:

  • Bước 1: Gõ lệnh LAYISO (hoặc phím tắt của lệnh) vào thanh Command và nhấn Enter (hoặc phím Space). Step 1: Type the LAYISO command (or its shortcut) into the Command bar and press Enter (or Space).
  • Bước 2: Click chuột chọn vào một (hoặc nhiều) đối tượng thuộc layer mà bạn muốn giữ lại trên màn hình. Step 2: Click to select one (or more) objects belonging to the layer you want to keep on the screen.
  • Bước 3: Nhấn Enter để kết thúc lệnh. Step 3: Press Enter to end the command.

Ngay lập tức, bạn sẽ thấy chỉ còn lại các đối tượng thuộc layer bạn vừa chọn, các layer khác sẽ bị ẩn hoặc làm mờ đi.

Immediately, you will see only the objects belonging to the layer you just selected remain, other layers will be hidden or faded.

2. Thiết lập cách hiển thị cho lệnh LAYISO (Tắt hẳn hoặc Làm mờ)

2. Setting the display mode for the LAYISO command (Turn off completely or Fade)

Từ các phiên bản AutoCAD đời cao (từ 2008 trở đi), mặc định khi sử dụng lệnh LAYISO, các layer không được chọn sẽ không biến mất hoàn toàn mà chuyển sang trạng thái bị khóa và làm mờ (Lock and fade).

From higher AutoCAD versions (2008 onwards), by default when using the LAYISO command, unselected layers do not disappear completely but switch to a locked and faded state (Lock and fade).

Nếu bạn muốn khi dùng lệnh LAYISO, các layer khác phải tắt hoàn toàn (biến mất khỏi màn hình) cho đỡ rối mắt, bạn cần thay đổi thiết lập Setting của lệnh theo các bước sau:

If you want that when using the LAYISO command, other layers must be completely turned off (disappear from the screen) to reduce clutter, you need to change the Setting configuration of the command according to the following steps:

  • Bước 1: Gõ lệnh LAYISO và nhấn Enter. Step 1: Type the LAYISO command and press Enter.
  • Bước 2: Khoan hãy chọn đối tượng! Gõ phím S (để gọi tùy chọn Settings) và nhấn Enter. Step 2: Hold on before selecting objects! Type S (to call the Settings option) and press Enter.
  • Bước 3: Trên dòng nhắc lệnh sẽ xuất hiện tùy chọn [Off/Lock and fade]. Step 3: On the command prompt, the option [Off/Lock and fade] will appear.
    • Gõ O (chọn Off) và nhấn Enter nếu bạn muốn các layer khác bị tắt và biến mất. Type O (choose Off) and press Enter if you want other layers to be turned off and disappear.
    • Gõ L (chọn Lock and fade) nếu bạn muốn các layer khác bị khóa và làm mờ. Type L (choose Lock and fade) if you want other layers to be locked and faded.
  • Bước 4: Nếu ở bước 3 bạn chọn O (Off), CAD sẽ hỏi thêm bạn muốn thiết lập trong không gian Layout Viewport như thế nào [Vpfreeze/Off]. Bạn gõ tiếp O (Off) và nhấn Enter để áp dụng tắt layer trên toàn bộ bản vẽ. Step 4: If in step 3 you chose O (Off), CAD will ask further how you want to set it in the Layout Viewport space [Vpfreeze/Off]. You continue typing O (Off) and press Enter to apply turning off layers across the entire drawing.
  • Bước 5: Bây giờ bạn có thể click chọn đối tượng cần cô lập và nhấn Enter như bình thường. Step 5: Now you can click to select the object to isolate and press Enter as normal.
💡 Lưu ý: 💡 Note:

Thiết lập này chỉ cần thực hiện 1 lần. AutoCAD sẽ tự động lưu lại cấu hình này cho tất cả các lần dùng lệnh LAYISO về sau (kể cả khi bạn tắt và mở lại CAD).

This setting only needs to be done once. AutoCAD will automatically save this configuration for all subsequent uses of the LAYISO command (even when you close and reopen CAD).

3. Lệnh LAYUNISO - Khôi phục trạng thái Layer

3. LAYUNISO Command - Restore Layer State

Sau khi đã hoàn tất việc chỉnh sửa trên layer được cô lập bằng lệnh LAYISO, bạn cần đưa bản vẽ trở về trạng thái hiển thị ban đầu.

After finishing editing on the layer isolated by the LAYISO command, you need to return the drawing to its original display state.

Cách thực hiện:How to do it:

  • Gõ lệnh LAYUNISO và nhấn Enter. Type the LAYUNISO command and press Enter.
  • Toàn bộ các layer bị tắt hoặc làm mờ trước đó sẽ ngay lập tức hiển thị lại bình thường. All previously turned off or faded layers will immediately display normally again.

4. Lời khuyên giúp thao tác nhanh hơn

4. Advice to help operate faster

Vì LAYISO và LAYUNISO là hai lệnh được dùng liên tục trong quá trình vẽ, việc gõ nguyên chữ sẽ rất mất thời gian. Bạn nên thay đổi phím tắt cho hai lệnh này thành các phím dễ bấm bằng tay trái.

Because LAYISO and LAYUNISO are two commands used continuously during the drawing process, typing the full words will be very time-consuming. You should change the shortcuts for these two commands to easy-to-press keys with your left hand.

Ví dụ phổ biến:

Common examples:

  • Đổi LAYISO thành phím 1Change LAYISO to key 1
  • Đổi LAYUNISO thành phím 2Change LAYUNISO to key 2

Bạn có thể đổi phím tắt thông qua công cụ ALIASEDIT (thuộc bộ Express Tools) hoặc chỉnh sửa trực tiếp trong file acad.pgp (Vào tab Manage -> Edit Aliases).

You can change the shortcuts via the ALIASEDIT tool (belonging to Express Tools) or edit directly in the acad.pgp file (Go to the Manage tab -> Edit Aliases).

Ngoài ra, một giải pháp cực kỳ tiện lợi và được sử dụng rộng rãi bởi các kỹ sư là dùng Lisp quản lý Layer (L1, L2, L3...). Bộ lisp này giúp gán sẵn các phím tắt siêu tốc cho hàng loạt thao tác quản lý layer mà không cần phải thiết lập thủ công.

Additionally, an extremely convenient solution widely used by engineers is using a Layer Management Lisp (L1, L2, L3...). This lisp set helps pre-assign super-fast shortcuts for a series of layer management operations without having to set them up manually.
