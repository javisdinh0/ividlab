iVidLab Shear (CC1) 2.15P — có gì mới

Từ bản 2.07P, Shear (CC1) bổ sung ô Assy Pos/No để cấp mã cụm riêng cho tấm không hàn, ô Class ở tab General hoạt động lại, tab Welds gọn hơn, thêm tab About kèm nhật ký chẩn đoán, ô tick lọc làm lại và nhận diện máy ổn định hơn.

  • Phiên bản 2.15P
  • Phát hành 15/11/2026
  • Tekla 2016 trở lên
⬇ Tải bản 2.15P Xem bài giới thiệu Shear (CC1)

Tóm tắt nhanh

  • Assy Pos/No: ô mới ở tab Parts, cấp mã cụm riêng cho tấm không hàn.
  • Class: ô Class ở tab General hoạt động lại.
  • Tab Welds: nhãn ô No gọn hơn, bỏ nút thừa.
  • Tab About và nhật ký chẩn đoán như PEB Bracket.
  • Ô tick lọc làm lại.
  • License: cài lại Windows vẫn dùng lại Active Key cũ.

1. Ô Assy Pos/No ở tab Parts

Tấm không hàn vào cụm nào thì trước đây không có chỗ đặt mã cụm riêng. Nay tab Parts có ô Assy Pos/No để cấp mã cụm cho các tấm này.

2. Ô Class ở tab General hoạt động lại

Ô Class ở tab General nhận giá trị bạn nhập và áp vào các chi tiết của liên kết.

3. Tab Welds gọn hơn

Nhãn ô No được thu hẹp và bỏ một nút thừa, bảng đọc gọn hơn.

Đã thử bản 2.13P trên: Tekla Structures 2016, 2017, 2020, 2022, 2025 và 2026. Các phần sửa của 2.05P đến 2.07P cho kết quả giống hệt 2.07P. Chưa thử trên Tekla 2021. Nếu gặp vấn đề trên phiên bản hoặc SP nào, vui lòng phản hồi để chúng tôi sửa.

4. Tab About và nhật ký chẩn đoán

Tab About giống PEB Bracket: Website, Contact, Copyright và các nút Copy path, Open, Open folder để mở nhật ký chẩn đoán. Khi gặp lỗi, bạn gửi nhật ký này để chúng tôi đọc lỗi từ máy của bạn.

5. Ô tick lọc làm lại

  • Gõ giá trị vào ô thì ô tick lọc tự tick.
  • Bỏ tick thì giữ nguyên trạng thái đó khi Modify.
  • Apply hoặc OK đưa ô đã bỏ tick về giá trị mặc định.

6. License: nhận diện máy ổn định hơn

Product Key nay gắn với serial bo mạch và BIOS. Một số máy (thường là máy lắp ráp) có mã bo mạch mặc định của nhà sản xuất, trước đây mỗi lần cài lại Windows thì Product Key đổi và phải xin Active Key mới. Từ bản này, cài lại Windows vẫn dùng lại được Active Key cũ. Máy bình thường không thay đổi gì, key đã cấp dùng tiếp.

7. Cách nâng cấp

  1. Ở mục Tải về bên dưới, tải gói iVidLab.FloorBeamGusset_2.15P.tsep.
  2. Đóng Tekla, rồi cài đè gói .tsep mới: nhấp đúp file, tick phiên bản Tekla và bấm Import.
  3. Liên kết đã có trong model chỉ được dựng lại theo bản mới khi Modify (nháy đúp liên kết, bấm Modify) hoặc khi Tekla cập nhật liên kết đó. Tệp thuộc tính và liên kết tạo bằng bản cũ vẫn dùng được.
Release // v2.15P

iVidLab Shear (CC1) 2.15P — what's new

Since 2.07P, Shear (CC1) adds an Assy Pos/No box to give unwelded plates their own assembly number, the Class box on the General tab works again, and the Welds tab is tidier, an About tab with a diagnostic log is added, the filter checkboxes are reworked and machine identification is more stable.

  • Version 2.15P
  • Released Nov 15, 2026
  • Tekla 2016 or newer
⬇ Download 2.15P Read the Shear (CC1) overview

At a glance

  • Assy Pos/No: new box on the Parts tab that gives unwelded plates their own assembly number.
  • Class: the Class box on the General tab works again.
  • Welds tab: narrower No label and an extra button removed.
  • About tab and diagnostic log as in PEB Bracket.
  • Filter checkboxes reworked.
  • License: an old Active Key survives a Windows reinstall.

1. Assy Pos/No box on the Parts tab

Plates that are not welded to any assembly had no place to set an assembly number. The Parts tab now has an Assy Pos/No box to assign one to these plates.

2. The Class box on the General tab works again

The Class box on the General tab takes the value you enter and applies it to the connection's parts.

3. Tidier Welds tab

The No box label is narrower and an extra button is removed, so the table reads more cleanly.

Version 2.13P tested on: Tekla Structures 2016, 2017, 2020, 2022, 2025 and 2026. The fixes from 2.05P to 2.07P give identical results to 2.07P. Not yet tested on Tekla 2021. If you hit a problem on any version or service pack, please send us feedback so we can fix it.

4. About tab and diagnostic log

The About tab is like PEB Bracket's: Website, Contact, Copyright and the Copy path, Open and Open folder buttons for the diagnostic log. When something goes wrong, send us this log so we can read the error from your machine.

5. Reworked filter checkboxes

  • Typing a value in a box ticks its filter checkbox automatically.
  • An unticked box stays unticked on Modify.
  • Apply or OK returns an unticked box to its default value.

6. License: more stable machine identification

The Product Key is now tied to the motherboard serial and the BIOS. Some machines (usually self-assembled ones) carry the manufacturer's default board ID, so every Windows reinstall used to change the Product Key and a new Active Key had to be requested. From this version, after reinstalling Windows you can reuse your old Active Key. Normal machines are unchanged and issued keys keep working.

7. How to upgrade

  1. In the Download section below, get iVidLab.FloorBeamGusset_2.15P.tsep.
  2. Close Tekla, then install the new .tsep over the old one: double-click it, tick your Tekla version and click Import.
  3. Connections already in the model are only rebuilt with the new version on Modify (double-click the connection, click Modify) or when Tekla updates that connection. Property files and connections made with older versions still work.
