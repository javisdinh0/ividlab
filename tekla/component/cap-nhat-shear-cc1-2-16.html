Bản cập nhật // v2.16P

Shear (CC1) 2.16P — Cải tiến khả năng nhận dầm tổ hợp thay đổi tiết diện nhiều lần và tăng cường khả năng bám liên kết khi copy

Từ bản 2.15P, ô lba (hàng bu-lông trên cùng cách mặt trên dầm sàn) cho phép nhập số âm như liên kết gốc; bu-lông căn giữa bụng dầm phụ đổi tiết diện nhiều lần; và có hướng dẫn copy để liên kết đi theo: nên chọn assembly, nếu chọn PEB component thì phải chọn cả liên kết.

  • Phiên bản 2.16P
  • Phát hành 26/11/2026
  • Tekla 2016 trở lên
⬇ Tải bản 2.16P Xem bài giới thiệu Shear (CC1)

Tóm tắt nhanh

  • Số âm ở bu-lông: ô lba nhận số âm (ví dụ −50), cả liên kết dầm–dầm lẫn dầm–cột.
  • Dầm tổ hợp đổi tiết diện nhiều lần (ví dụ 300–600–300): cụm bu-lông căn đúng tâm bụng dầm phụ tại vị trí bu-lông.
  • Copy: nên chọn assembly. Nếu chọn PEB component thì phải chọn thêm cả liên kết để liên kết đi kèm.

1. Ô lba nhận số âm

Ô lba là khoảng cách từ mặt trên dầm sàn tới hàng bu-lông trên cùng. Trước đây khi nhập số âm (ví dụ -50), giá trị bị bỏ qua và hàng bu-lông quay về mặc định căn giữa. Từ 2.16P số âm được nhận đúng như liên kết gốc, ở cả liên kết dầm–dầm và dầm–cột. Đã đối chiếu với liên kết gốc trên cùng hình học với các giá trị lba 50, −20, −50, −100, −150, trên dầm thẳng và dầm dốc.

2. Dầm tổ hợp thay đổi tiết diện nhiều lần

Dầm phụ vát hoặc đổi tiết diện dọc trục (ví dụ PEB 300–600–300) có chiều cao bụng tại vị trí bu-lông khác với chiều cao đo ở đầu dầm. Bản này đo lại tiết diện tại tâm cụm bu-lông nên bu-lông căn đúng tâm bụng. Đo trên Tekla 2021 SP11, độ lệch tâm bu-lông so với tâm bụng giảm từ 1,25–2,5 mm xuống còn khoảng 0,02 mm ở 4 dạng dầm: 300–600–300, 600–300–600, vát một đoạn và 450 không vát. Dầm lăng trụ và dầm dốc không đổi so với trước.

Các sửa từ 2.06P–2.07P cho dầm PEB nhiều đoạn (không kéo dài tấm bụng, bản mã bám mặt cánh nghiêng) vẫn giữ nguyên.

3. Copy: chọn gì để liên kết đi theo

Khi bạn copy dầm PEB (Copy Special, Linear…), Tekla chạy lại component PEB tại vị trí mới, nên các tấm bản sao là chi tiết mới và liên kết gắn vào tấm cũ không tự đi theo. Cách chọn quyết định kết quả:

  1. Chọn assembly (khuyên dùng): bản sao có đủ liên kết, bản mã và bu-lông.
  2. Chọn PEB component và chọn thêm liên kết: kéo khung chọn quanh đầu dầm phụ (mặc định chọn đúng component và liên kết), hoặc chọn PEB component rồi giữ Ctrl / Shift bấm thêm liên kết. Bản sao có đủ liên kết và vẫn giữ component PEB.
  3. Chỉ bấm chọn PEB component: bản sao không có liên kết.
  4. Chỉ chọn các tấm (parts): liên kết đi theo nhưng bản sao mất component PEB (chỉ còn các tấm rời).

Đã thử Copy Special trên Tekla 2021 SP11 (liên kết đi theo khi chọn component cùng liên kết) và Tekla 2017 SP4 (chọn assembly). Phần dò vai dầm chính/dầm phụ của bản sao đã có từ 2.14P, bản này kèm hướng dẫn cách chọn.

Đã thử trên: Tekla Structures 2021 SP11 cho phần lba âm và bu-lông dầm đổi tiết diện, 2017 SP4 và 2021 SP11 cho phần copy. Nếu gặp vấn đề trên phiên bản hoặc SP nào, vui lòng phản hồi để chúng tôi sửa.

4. Cách nâng cấp

  1. Ở mục Tải về bên dưới, tải gói iVidLab.FloorBeamGusset_2.16P.tsep.
  2. Đóng Tekla, rồi cài đè gói .tsep mới: nhấp đúp file, tick phiên bản Tekla và bấm Import.
  3. Liên kết đã có trong model chỉ được dựng lại theo bản mới khi Modify (nháy đúp liên kết, bấm Modify) hoặc khi Tekla cập nhật liên kết đó. Tệp thuộc tính và liên kết tạo bằng bản cũ vẫn dùng được.
Release // v2.16P

Shear (CC1) 2.16P — Better handling of built-up beams with several section changes, and connections that stay attached when you copy

Since 2.15P, the lba box (top bolt row, measured from the top of the floor beam) accepts negative numbers like the original connection; bolts are centred on the web of a secondary beam that changes section several times; and there is guidance for copying so the connection follows: select the assembly, or, if you select the PEB component, select the connection too.

  • Version 2.16P
  • Released Nov 26, 2026
  • Tekla 2016 or newer
⬇ Download 2.16P Read the Shear (CC1) overview

At a glance

  • Negative bolt offset: the lba box accepts negative numbers (e.g. −50), for both beam-to-beam and beam-to-column connections.
  • Built-up beams with several section changes (e.g. 300–600–300): the bolt group is centred on the secondary beam's web at the bolt position.
  • Copy: select the assembly. If you select the PEB component, select the connection as well so it comes along.

1. The lba box accepts negative numbers

lba is the distance from the top of the floor beam to the top bolt row. Previously a negative value (e.g. -50) was ignored and the row fell back to the centred default. From 2.16P negative values are honoured like the original connection, in both beam-to-beam and beam-to-column connections. Checked against the original connection on the same geometry with lba = 50, −20, −50, −100, −150, on straight and sloping beams.

2. Built-up beams with several section changes

A tapered secondary beam, or one that changes section along its axis (e.g. PEB 300–600–300), has a web depth at the bolts that differs from the depth measured at the beam end. This version re-measures the section at the centre of the bolt group, so the bolts are centred on the web. Measured on Tekla 2021 SP11, the offset between bolt centre and web centre drops from 1.25–2.5 mm to about 0.02 mm on four shapes: 300–600–300, 600–300–600, one tapered segment and an untapered 450. Prismatic and sloping beams are unchanged.

The 2.06P–2.07P fixes for multi-segment PEB beams (no extended web plates, gusset following the sloping flange) are kept.

3. Copy: what to select so the connection follows

When you copy a PEB beam (Copy Special, Linear…), Tekla re-runs the PEB component at the new position, so the copied plates are new objects and a connection attached to the old plates does not follow by itself. What you select decides the result:

  1. Select the assembly (recommended): the copy has the connection, plates and bolts.
  2. Select the PEB component and the connection: drag a selection window around the secondary beam's end (by default it picks exactly the component and the connection), or select the PEB component and Ctrl / Shift-click the connection. The copy has the connection and keeps the PEB component.
  3. Select only the PEB component: the copy has no connection.
  4. Select only the parts: the connection follows but the copy loses the PEB component (loose plates only).

Tested with Copy Special on Tekla 2021 SP11 (connection follows when the component and connection are selected) and Tekla 2017 SP4 (assembly selected). The detection of main and secondary beam on the copy has been in since 2.14P; this version adds the selection guidance.

Tested on: Tekla Structures 2021 SP11 for negative lba and the bolts on changing-section beams, 2017 SP4 and 2021 SP11 for copying. If you hit a problem on any version or service pack, please send us feedback so we can fix it.

4. How to upgrade

  1. In the Download section below, get iVidLab.FloorBeamGusset_2.16P.tsep.
  2. Close Tekla, then install the new .tsep over the old one: double-click it, tick your Tekla version and click Import.
  3. Connections already in the model are only rebuilt with the new version on Modify (double-click the connection, click Modify) or when Tekla updates that connection. Property files and connections made with older versions still work.
